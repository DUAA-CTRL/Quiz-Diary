# 🖤 Quiz Diary ♡

A cute, interactive, and mobile-friendly quiz game built using HTML, CSS, and JavaScript. Test your knowledge with 10 random questions and discover interesting facts along the way!

## ✨ Features

* 🧠 10 multiple-choice quiz questions
* 🔀 Random question and answer order
* ✅ Instant feedback for correct and incorrect answers
* 💡 Interesting facts after each answer
* 📊 Progress indicator
* 🏆 Final score display
* 🔄 Play Again option
* 📱 Responsive and mobile-friendly design
* 🎀 Cute doodles and minimalist styling

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation

## 🚀 Live Demo

[**Play Quiz Diary ♡**](https://duaa-ctrl.github.io/Quiz-Diary/)

## ▶️ How to Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start answering the quiz questions!
